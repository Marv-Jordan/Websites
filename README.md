# Webseite: Stephan Martin Steinmetz

Eine fertige, statische One-Page-Website für Stephan Martin Steinmetz.

## Starten
1. `index.html` im Browser doppelklicken.
2. Für eine echte Website: Dateien per FTP, Netlify, GitHub Pages oder einem Hosting-Anbieter hochladen.

## Wichtige Platzhalter ersetzen
- Fotos in `assets/img/` durch echte Werkstatt-, Porträt- und Projektfotos ersetzen. Gleich Dateinamen beibehalten oder HTML-Pfade anpassen.
- In `index.html` Adresse, Telefonnummer und E-Mail-Adresse im Kontaktbereich ergänzen.
- Impressum und Datenschutzerklärung vor Veröffentlichung erstellen (in Deutschland Pflicht bei einer geschäftlichen Website).
- Das Kontaktformular currently zeigt nur eine Bestätigung; für echten Versand einen Formulardienst wie Formspree, Netlify Forms oder einen eigenen Mailserver anbinden.
- Stellenangebote und Anforderungen mit den tatsächlichen Informationen abgleichen.

## Struktur
- `index.html` – komplette Startseite
- `assets/css/styles.css` – Design
- `assets/js/main.js` – kleine Interaktionen
- `assets/img/` – Platzhalterbilder
